# Проверки версии Gemini + локальные модели

- 37 автоматических проверок прошла на Python 3.13.
- Проверен полный путь с одним Gemini adapter и двумя Ollama adapters на
  подставных ответах во временных каталогах: подсчёт, Holm, sensitivity, annotation.
- Проверены отсутствие ключа, декларация Free tier, HTTP 429 без retry,
  продолжение с сохранённого прогресса, смена модели/параметров/версии,
  отказ от пустых, обрезанных и заблокированных ответов, исключение thought parts.
- Ключ используется в x-goog-api-key, не в URL/файлах результатов; ошибки сервера
  не выводят тело ответа с потенциально чувствительными данными.
- Без подтверждения пользователем Free tier и отключённого billing генерация
  через CLI не начинается. Сам billing статус по ключу не подтверждается.
- Проверены локальные входные файлы: 430 items, 830 prompts/model.
- Без полных трёх реальных запусков итоговая таблица не создаётся.
- Gemini API реально не вызывался: API-ключ не предоставлен и квоты не проверены.
  Полные запуски, NLLB и экспертная разметка не выполнялись.
- Предыдущая локальная версия уже выполнила три реальных вызова установленной
  Gemma на этом MacBook. Это отдельная проверка, не новый benchmark и не Gemini.
- Бесплатная доступность и квоты конкретного Google проекта остаются
  внешним условием; обещания стоимости/дедлайна для непроверенного проекта нет.

## Исправление HTTPS на macOS

- Воспроизведена ошибка SSL_CERTIFICATE_VERIFY_FAILED стандартного Python.
- Подключён certifi с сохранением проверки сертификата и имени сервера.
- Исправленный adapter достиг Google по HTTPS на служебном GET-запросе с
  заведомо недействительным тестовым ключом. Получен ожидаемый отказ авторизации,
  а не TLS-ошибка. Настоящий пользовательский ключ и генерация не использовались.

## Исправление выбора модели после 404

- Зафиксирована ошибка пользователя: metadata 2.5 доступны, generateContent=404.
- Официальные материалы Google указывают, что legacy 2.5 могут быть недоступны
  новым проектам, несмотря на доступность metadata. Без тела исходной ошибки
  это наиболее вероятное объяснение, а не подтверждённый диагноз проекта.
- Конфигурация изменена на Gemini 3.5 Flash-Lite, Standard Free tier проверен
  в официальной таблице Google. Thinking MINIMAL и увеличенные token budgets
  зафиксированы. Подсчёт и обработка 404 прошли тесты.
- Живой вызов новой модели с пользовательским ключом не выполнялся.

## Демонстрационное меню

- Добавлены меню просмотра, выбор задания по номеру и один явный live-запрос.
- Три проверки подтверждают отсутствие сетевых вызовов в режиме просмотра,
  блокировку live без декларации Free tier и отдельное сохранение demo-ответа.
- Меню проверено на фактических записях пользовательского Gemini run и smoke QA.
- Сохранённый smoke QA-ответ A совпал с эталоном A в одном примере; это не общая точность.
- Полный запуск Gemini на момент проверки не завершён; локальные запуски в
  текущей поставке не выполнены. Нового реального live-запроса агент не отправлял.

- The English demo was exercised in an interactive Terminal on actual saved logs.
  All five choices, invalid input, return-to-menu pauses, and exit worked.
  The pending results view calculated baselines on the frozen dataset.
  The existing 37 automated checks passed.
